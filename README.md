# TripPilot AI – Multi-Agentic Travel Planner

## How to Run the Project

### 1. Create the Virtual Environment

```bash
conda create -n travel python=3.11 -y
```

### 2. Activate the Environment

```bash
conda activate travel
```

### 3. Install the Requirements

```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables

Create a `.env` file in the project root directory and add the required API keys and database connection URL.

### 5. Run the Application

Application startup instructions will be added after completing the project setup.

## Technology Stack
